# Swaramayi Real Estate Marketing & CRM

A comprehensive Real Estate Marketing & Lead Management System built for Swaramayi.

## Project Architecture

- **`backend/`**: Node.js & TypeScript backend service API with database configurations and data models.
- **`frontend/`**: Vite + React + TypeScript frontend dashboard for managing real estate leads, properties, campaigns, and interactions.
- **`docs/`**: Comprehensive project documentation including BRD, SRS, FRS, ER Diagrams, Database Design, API Documentation, Security Architecture, AI Workflow, Testing Plan, Deployment Guide, and SOPs.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### Backend Setup
```bash
cd backend
npm install
npm run dev
```
